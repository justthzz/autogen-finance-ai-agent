# autogen-finance-ai-agent

An AI-powered multi-agent system for automating financial coding, data analysis, and report generation. Built with Autogen and OpenAI’s GPT-4-turbo, this project consolidates all agent logic within a single Jupyter notebook for ease of experimentation and extension.

---

## Project Overview

This project leverages advanced LLM agents to streamline financial workflows by automating coding tasks, data interpretation, and insightful analysis. It demonstrates how multiple AI agents can collaborate inside a unified environment, enabling end-to-end automation in financial contexts.

---

## Features

- Multi-agent architecture implemented in one Jupyter notebook  
- Automated financial code generation and validation  
- Data analysis and financial report generation  
- Utilizes GPT-4-turbo for powerful language understanding  
- Configurable with environment variables for API keys  
- Modular design for easy customization and scaling
